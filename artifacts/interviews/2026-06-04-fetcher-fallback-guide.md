## 결정

**`session-fetcher` 에이전트 가이드를 다음 4 섹션으로 보강한다.**

1. **폴백 카탈로그** — `transcript 복붙` / 외부 사이트 다운로드 → 파일 경로 / 자막 파일(.srt/.vtt) 직접 전달 3가지 채널 명시. 외부 사이트 이름은 본문에 박지 않고 *예시 1개* (`예: downsub.com`) 만
2. **저장 경로 규약** — `artifacts/<slug>/transcripts/<session-slug>.<lang>.<ext>` 표준화. 폴백 입력도 이 경로에 저장하도록 안내
3. **영상 메타 자동 보고 의무화** — fetcher 가 yt-dlp 메타데이터 추출(영상 제목·업로드 날짜·발표자 가능 시)을 자동 보고. 매핑 검증(마킹 세션 vs 실제 영상) 사전 가능
4. **자동화 채널 인터페이스 규약 (A+B 결합)** — 환경변수 이름·호출 시점은 본문에 명시, *어떤 외부 서비스 쓸지·요청 형식·응답 파싱* 은 `examples/<slug>/auto-fetch-case.md` 사례 박제로 격리

## 남은 모름 (회고 후보)

- 환경변수 이름 결정 (`TRANSCRIPT_API_KEY` 등) — 보강 작업 시 결정
- 자동화 채널 첫 사례 박제 대상 (transcriptapi.com 외 후보 검토할지)
- API key 보호 `.gitignore` 패턴 (예: `.env.local`, `.secrets/`)
- analyzer 한국어 자막 입력 명시 — **별도 인터뷰 필요** (옵션 #4 미포함)
- 노트 생성 후 상태 자동 전이 정책 — **별도 인터뷰 필요**
- 자동화 채널 호출 시 사용자 의도 확인 흐름 (자동 호출 vs 사전 동의) — 후속 좁힘 가능
