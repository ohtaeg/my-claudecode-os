# conference-status

행사 진척 카운트 조회 스킬. 단일 책임: **한 행사의 분류 카운트를 한 줄로 출력**.

## 입력

- 행사 슬러그

호출 예시:
```
/conference-status aws-summit-seoul-2026
```

## 처리 흐름

1. `artifacts/conferences/<행사>/README.md` 읽기
2. 상단에 박힌 `진척:` 라인 사용 (또는 세션 테이블 직접 집계해서 검증)
3. 행사 표시명 + 카운트를 한 줄로 출력

## 출력 형식

```
AWS Summit Seoul 2026
  들음 12 / 관심 8 / 미정 5 / 스킵 0  (총 25)
```

## 폴백·실패 처리

| 트리거 | 대응 |
|---|---|
| 행사 폴더 없음 | "그 행사가 아직 등록되지 않았어요. `/conference-import` 먼저 실행하세요" 안내 |
| README 의 `진척:` 라인 없음·손상 | 세션 테이블을 직접 집계해서 출력 + "README 카운트 라인 미발견" 경고 |
| 진척 라인과 세션 집계가 불일치 | 양쪽 모두 출력 + 사용자에게 동기화 권유 (`session-mark` 한 번 호출하면 재계산됨) |

## 절대 하지 않을 것

- ❌ **세션 목록 출력** — 카운트만. 세션 목록은 `/conference` 스킬 영역
- ❌ **상태 변경** — 읽기 전용
- ❌ **전체 행사 조회** — 한 행사만. 여러 행사 인덱스 조회는 OS 가 의도적으로 만들지 않는 영역
- ❌ **자동 동기화** — 불일치 감지해도 자동 수정하지 않는다. 사용자에게 알리기만
