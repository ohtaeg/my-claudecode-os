# session-preview

한 세션 미리보기 스킬. 단일 책임: **세션 메타데이터 + 분류 상태 + 노트 TL;DR (있으면) 압축 출력**.

## 입력

- 행사 슬러그
- 세션 식별자 — 다음 중 하나:
  - **세션 ID** (`S1` ~ `SN`) — README 표의 ID 컬럼 값. **가장 권장**
  - **세션 슬러그** (`catchtable-bedrock-proxy`) — 노트 생성된 세션에만 존재
  - **제목 키워드** — 제목 일부 (대소문자 무시)

호출 예시:
```
/session-preview aws-summit-seoul-2026 S51            # ID 기반 (권장)
/session-preview aws-summit-seoul-2026 캐치테이블     # 제목 키워드
```

## 처리 흐름

1. `artifacts/conferences/<행사>/README.md` 에서 해당 세션 행 찾기 — 다음 순서로 매칭:
   1. **세션 ID 정확 매칭** (`S\d+` 패턴 우선)
   2. **세션 슬러그 정확 매칭**
   3. **제목 키워드 부분 매칭** (대소문자 무시)
2. 메타데이터·상태 확보
3. `artifacts/conferences/<행사>/sessions/<세션 슬러그>.md` 확인:
   - 파일 있으면 → frontmatter + TL;DR 섹션 읽기
   - 파일 없으면 → "아직 학습 노트 없음" 표시
4. 압축 미리보기 형식으로 출력

## 출력 형식

```
[제목]   AWS Bedrock Deep Dive
[발표자] 홍길동
[상태]   관심
[URL]    https://www.youtube.com/watch?v=...
[태그]   Bedrock, GenAI, Foundation Models

[TL;DR]
Bedrock 의 모델 라우팅 전략으로 비용 30% 절감한 사례.
핵심은 작은 모델 우선 폴백 구조.
```

노트가 없으면 `[TL;DR]` 자리에 `아직 학습 노트 없음` 표시.

## 폴백·실패 처리

| 트리거 | 대응 |
|---|---|
| 행사 폴더 없음 | "그 행사가 아직 등록되지 않았어요" 안내 |
| 세션 못 찾음 | 비슷한 세션 후보 1~3개 제시 |
| 세션 노트 없음 | 메타데이터·상태만 출력 + "아직 학습 노트 없음" |
| 노트 frontmatter 손상 | TL;DR 만 출력 시도, 실패 시 "노트 파일 손상" 경고 |

## 절대 하지 않을 것

- ❌ **노트 전체 출력** — TL;DR 만. 전체는 사용자가 직접 파일 열어 봄
- ❌ **추측해서 채우기** — 노트 없으면 "아직 없음" 명시. 자체 요약 생성 금지
- ❌ **마킹 변경** — 이 스킬은 읽기 전용
- ❌ **인사이트·태그 임의 보강** — 노트에 있는 것만 그대로
