# conference

행사 세션 목록 조회 스킬. 단일 책임: **한 행사의 모든 세션 이름 + 상태 + 노트 유무를 표로 출력**.

## 입력

- 행사 슬러그

호출 예시:
```
/conference aws-summit-seoul-2026
```

## 처리 흐름

1. `artifacts/conferences/<행사>/README.md` 읽기
2. 세션 테이블에서 모든 행 추출
3. 상태별로 그룹화해서 표로 출력 (들음 → 관심 → 미정 → 스킵 순)

## 출력 형식

```
AWS Summit Seoul 2026 — 총 25 세션

| 상태  | 세션 이름                       | 노트 |
|------|--------------------------------|-----|
| 들음 | Keynote                        | —   |
| 들음 | 모더나이즈드 데이터 플랫폼      | —   |
| 관심 | Bedrock Deep Dive              | ✓   |
| 관심 | EC2 Spot 전략                  | —   |
| 미정 | Networking 101                 | —   |
| 스킵 | (생략된 세션)                  | —   |
...
```

- 노트 컬럼은 `sessions/<세션>.md` 존재 여부로 결정 (✓ / —)
- 상태별로 묶어서 보여주면 한눈에 잘 들어옴

## 폴백·실패 처리

| 트리거 | 대응 |
|---|---|
| 행사 폴더 없음 | "그 행사가 아직 등록되지 않았어요. `/conference-import` 먼저 실행하세요" 안내 |
| README 의 세션 테이블 손상 | 손상된 행은 `(파싱 실패)` 로 표시하고 나머지 출력 |
| 세션 0개 | "이 행사에 등록된 세션이 없어요" 안내 |

## 절대 하지 않을 것

- ❌ **세션 내용·인사이트 출력** — 이름·상태만. 내용 미리보기는 `/session-preview` 영역
- ❌ **상태 변경** — 읽기 전용
- ❌ **전체 행사 조회** — 한 행사만. 여러 행사 인덱스 조회는 의도적으로 만들지 않는 영역
- ❌ **세션 추가·삭제** — 이 스킬은 README 의 세션 테이블을 그대로 보여줄 뿐. 변경은 `conference-import` / `session-mark` 영역
